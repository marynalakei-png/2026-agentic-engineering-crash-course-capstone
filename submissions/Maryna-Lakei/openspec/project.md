# AI Requirements Assistant

Public desktop web demo for a Business Analyst. One workflow: enter a raw business request, click Generate, review a User Story, Acceptance Criteria, and Clarifying Questions.

Stack: Next.js App Router, server-side LLM, Vitest, Playwright (Chromium), OpenSpec, Vercel. No auth, database, email, or payments.

Requirements: `docs/requirements.md` (owner-confirmed 2026-09-30).
